# Checkpoint scope and dataset terms

These Hexel scene/image checkpoints are shared for research evaluation. The
authors' source code uses MIT; that software license does not relicense the
underlying datasets, scene content or image content. Source images, reference
geometry and baseline weights are not included. Retain the relevant benchmark
citations and comply with the applicable dataset/content terms.

| Dataset | Original source and attribution | Terms relevant to this release |
|---|---|---|
| Mip-NeRF 360 | [Barron et al., CVPR 2022](https://jonbarron.info/mipnerf360/) | Follow the terms and attribution accompanying the author-provided data. |
| DTU | [Jensen et al., CVPR 2014; Aanaes et al., IJCV 2016](https://roboimagedata.compute.dtu.dk/?page_id=36) | The official page describes freely available MVS evaluation data and requests citation; it does not assign a standard model-weight license. |
| Tanks and Temples | [Knapitsch et al., SIGGRAPH 2017](https://www.tanksandtemples.org/) and [official license](https://www.tanksandtemples.org/license/) | The page contains both a CC BY 4.0 sharing statement and restrictive noncommercial/redistribution language. This release does not resolve the conflicting language or claim unrestricted reuse. |
| Image-GS image benchmark | [Zhang et al., Image-GS](https://github.com/NYU-ICL/image-gs#setup) | The Image-GS software is MIT, but no separate image-set license was found in the downloaded data. Encoded models can reconstruct the source images; underlying image rights remain relevant. |

Public research availability is not a blanket
redistribution or commercial-use grant. This repository does not grant rights
that belong to the dataset publishers or content owners. Consult the original
publishers where permission for your intended use is unclear.

Original software/metadata attribution is retained in `SOURCE_CODE_LICENSE.txt`.
The GitHub code release separately retains all kernel and adapted-baseline
licenses. No general legal certification is claimed by this inventory.
