# Retained dependency license snapshots

These files preserve complete, unmodified publisher-supplied license text files from the reference Python support-tool environment inspected on 2026-10-28. [dependency_licenses.json](dependency_licenses.json) records distribution versions, relative source paths, official upstream repositories, byte lengths and SHA-256 hashes. The OpenCV packaging license and its complete accompanying third-party notice file are both retained.

The Python packages and wheels themselves are **not vendored or bundled in the native app**. These snapshots do not turn dependency requirements into exact pins, cover future package versions, or replace a downloaded wheel's complete set of bundled-library notices. Preserve that exact distribution's licenses if redistributing its code/binaries. The original project MIT license does not override these texts.

See [the package inventory](../THIRD_PARTY.md) for dependency scope, SDK boundaries, dataset citations and asset provenance.
