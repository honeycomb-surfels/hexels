# nexels

Upstream: [nexels](https://github.com/victor-rong/nexels), pinned to `e975afad5b301b843a75f3a60f234aea4406aa77`.

Adds shared camera conventions and count controls. Memory controls account for the hash grid and appearance network as well as the primitive rows.
