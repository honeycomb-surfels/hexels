# Fused SSIM

Upstream: [Rahul Goel/fused-ssim](https://github.com/rahul-goel/fused-ssim.git), revision `1272e21a282342e89537159e4bad508b19b34157`.

The original [MIT license](LICENSE) is retained. This is an unmodified optional 3D loss implementation and a dependency of the Image-GS image-fitting adapter. Fetch with `python -m scripts.fetch_baselines --methods fused-ssim`, then build with `python -m pip install --no-build-isolation ./fused-ssim` on a GPU machine.
